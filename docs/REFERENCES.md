# 参考的开源组织方式

核对日期：2026-10-23。星数会变化，不代表本项目与这些仓库存在合作。

| 项目 | 当日 GitHub API stars | 本项目借鉴的组织方式 |
| --- | ---: | --- |
| [VPet](https://github.com/LorisYounger/VPet) | 7020 | 动图直接展示动作、普通用户入口、代码和动画权利分别说明 |
| [OpenPets](https://github.com/OpenPetsHQ/openpets) | 1328 | 先说明如何下载使用、角色画廊、源码与发行入口分开 |
| [Petdex](https://github.com/crafter-station/petdex) | — | 一个角色一个文件夹、元数据加图集、清晰标出宿主依赖 |

本项目自行编写工具和预览器，没有复制参考项目的源代码、角色或安装程序。
没有声称已接入 VPet、OpenPets 的运行时；本发布仅交付已有 legacy 8×9 包。
