# 使用与安装

## 先预览

解压仓库，双击根目录 `index.html`。全部资源在本地，断网可用。
切换版本与状态观察透明底、姿态和速度；「减少动态效果」或系统减少动画偏好会暂停自动播放。
网页是预览器，不是桌面置顶窗口。

## Petdex / 兼容角色包的桌面宿主

从 [Petdex 官方下载页](https://petdex.dev/download) 获取宿主。此仓库不捆绑其安装程序。
每套角色目录包含 `pet.json`、`spritesheet.webp`、备用 PNG 和动作时序说明。
按宿主支持的本地角色目录 / 导入流程加入 `pets/capri-clear/`（也可选另外两套）。
若宿主只扫描自己的 pets 目录，复制完整角色文件夹到该目录，再刷新 / 重启宿主。
自定义目录入口和数据路径随宿主版本变化，请参考宿主当前说明；不要覆盖原来的同名角色。
本仓库给三套角色设置不同 ID，便于同时保留。

可选的命令行复制工具只写入你明确指定的目标，默认不会猜测或修改应用设置：

```powershell
python scripts/install.py --pet capri-clear --destination "F:\Pets"
```

以上命令仅复制为 `F:\Pets\capri-clear`；需要将该位置配置给支持自定义目录的宿主。
目标已有内容时会拒绝覆盖。

## ChatGPT / Codex 系列宠物

请先检查自己版本提供的宠物上传 / 本地角色功能。
[官方 Pets 文档](https://learn.chatgpt.com/docs/pets)描述了桌面创建、刷新选择以及 Web 上传入口。
当界面提供 **Upload pet** 时，选择 `pets/capri-clear/spritesheet.webp` 或 PNG；这份 legacy
图集为 1536×1872，文件小于 20MiB。上传后在同一设置中选择它。

不同客户端、账号和版本可能要求新格式或只支持内置角色。本仓库不修改客户端二进制，
不保证所有版本可导入；如果宿主要求 16 向 look 或更多行，请勿改一个版本号冒充新格式。
图集本身可直接在本仓库的离线预览器中检查。

## 常见问题

- 没有桌面悬浮：浏览器预览与桌面宿主是两个用途，需要启动兼容宿主。
- 清晰版播放过快：应用通常控制播放速度，可能不读取本包的 `durationsMs`。
- 像素版细节较少：⑤是48×52逻辑单帧的有损像素化，选⑥可保留更多纹理。
- ③旧元数据写着版本2：原始字段已归档，发布包按实际8×9几何归一为版本1；未添加任何新方向帧。
